# CIELO MAR

CIELO MAR is an original third-person open-world crime story set in a sun-soaked coastal city. Follow wheelman Rafa Quintero through eight connected missions, steal and drive distinctive vehicles, outrun a five-star municipal police response, explore six districts on foot, and build a crew among marinas, old plazas, dockyards, hillside villas and dense neighbourhood streets. The complete game runs locally in desktop Chrome with procedural geometry, a live minimap, synthesised audio and persistent saves.

## Play

Serve `game/` with any static file server, then open `index.html` in desktop Chrome. With Node 22 or newer, run `node serve.ts` from the repository root and use the local address it prints. No installation, build step, account or network connection is required.

Choose **New Game**. Use **WASD** to move or drive, the **mouse** to look, **Shift** to sprint, **Space** to jump or handbrake, **F** to enter or leave a vehicle, and **1–4** to select fists, Pistola, Subfusil or Escopeta. Hold **right mouse** to aim, **left mouse** to fire, **R** to reload or change radio station, **Tab** for the weapon wheel, and **Esc** to pause. Follow the amber waypoint and objective card; save at Rafa's safehouse.

## Structure

`main.ts` copies `game/` and the four browser screenshots to the output directory and builds the competition dossier. The game uses native ES modules under `game/src/`: one module each for configuration, input, rendering, city generation, player combat, vehicles and traffic, pedestrians, police, missions, HUD, menus, saves, audio and deterministic screenshot staging. The only vendored runtime is the supplied `game/vendor/three.min.js`; all city art, effects, characters, interface and sound are generated by the game's own source.
